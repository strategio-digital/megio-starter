# Collections (Admin CRUD)

Collections provide admin panel CRUD functionality for entities.

## External Documentation

Complete Collections documentation is available at:

**[https://megio.dev/docs/collections](https://megio.dev/docs/collections)**

The external documentation covers:

- **Recipes** - Defining CRUD behavior for entities
- **ReadBuilder** - Configuring list and detail views
- **WriteBuilder** - Configuring create and update forms
- **SearchBuilder** - Search, filtering, and pagination
- **Field types** - Available form fields and validators
- **Permissions** - Role-based access control
- **Events** - Collection lifecycle events
